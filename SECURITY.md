# Security Policy

This wallet is **experimental and has not been audited**. It should not hold real funds. See the README for the known limitations.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private vulnerability reporting (Security tab → "Report a vulnerability"), or email tdreamon42@gmail.com.

Include a description, reproduction steps and the affected commit. Expect a first response within about 7 days.
